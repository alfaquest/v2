Alfaquest sequencing tutorial

How starting letters chain together — and why some paths dead-end early.

Objective

Navigate a sequence of country names. Each answer must use a unique starting letter. The first answer always starts with A. Every later required letter comes from inside your previous answer — the first unused letter in that country name, reading left to right.

In the Countries category there are 24 valid starting letters (W and X are skipped). Win by completing all 24 without hitting a dead-end.

How the next letter is chosen

After each submission, scan the previous country name from the start. Skip any letter that has already been used as a starting letter earlier in your run. The first letter you have not used yet becomes the required start for your next answer.

On the play page, watch the gold required letter banner and the grid highlight — they show exactly which letter you need next.

Example — dead-end after 5 moves

This sequence ends the game on move 5:

Game over at Malta
  1. Albania
  2. Latvia
  3. Tonga
  4. Oman
  5. Malta

By move 5, starting letters A, L, T, and O are already used. Inside Malta, the only letters left are M, A, L, T, and A — all already used as starters. There is no unused starting letter left inside the word, so the game ends.

Notice how Latvia forces the next required letter to T (not A), because A was already used for Albania.

Example — avoiding the trap

Same run, but Malaysia on move 5 keeps the game alive:

Continues to move 6
  1. Albania
  2. Latvia
  3. Tonga
  4. Oman
  5. Malaysia

After Malaysia, the next unused letter inside the word is Y. You must submit a country starting with Y to reach move 7. Letters S and I inside Malaysia are not used for this rule.

Tip: Track used starting letters on the grid — blue cells are still available, muted cells are done.

Longer chains

As the run grows, the required letter can come from deep inside a long country name — position 4, 10, or even later. Only the first unused letter in the previous answer matters.

You win when all 24 starting letters are completed. You lose when no valid country can continue the chain, or when your last answer has no unused starting letter left inside it.

Scoring

Completed Alfaquest runs earn a score and rating. On the play page, enable Show scoring to see live points, per-answer deltas, and rating progress.

Letter rarity, move position, typing speed, and total run time all feed into your final score. Ratings run from Legendary down to Completed.
