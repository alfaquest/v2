How to play: Alfaquest enforces a sequencing rule: each submission must start with the required letter determined from previous entries, and starting letters cannot repeat (W and X are ignored because no countries begin with those letters). Submissions must be valid country names and should add at least one new letter. The game auto-resets when no moves remain.

    Scoring system

    Scoring v2 formula (blended)

    Each run now has three components:

    1. Raw points = (starting letter value × 2) + position bonus for each submission.
    2. Time-adjusted score = raw points × time factor, where time factor is based on target time / actual run time and capped between 0.90 and 1.10.
    3. Final score uses a weighted blend: 60% letter/raw influence and 40% timing influence, then scaled to the million-range leaderboard.

    Target time scales with run length (12 seconds per answer, minimum 120 seconds). Speed bonus is normalised by letters-per-second and capped per country and per run so short and long names stay balanced.
